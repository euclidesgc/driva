## 04 Binding — seletor (ícone de variável ao lado de "Text")

Global Properties (exemplos): Current Time, Current Device Location, Current Route Stack (List<String>), Fraction of Screen Width/Height, Screen Width, Screen Height, ...
## 05 Binding — configuração após escolher "Current Time"

Resultado: campo do painel vira chip laranja "Current Time"; canvas mostra "Current Time"; árvore de acessibilidade mostra "[Current Time]".

## Ação "Show Snack Bar" — parâmetros
Value (var) | Text Style: Theme Text Style "Custom", Font Family, Font Weight, Font Size, Text Color ("Primary Text" = cor do tema), Line Height, Letter Spacing, Text Align, Shadows | Background Value ("Secondary") | Duration (ms) | Hide Previous Snackbar
→ parâmetros de ação usam OS MESMOS editores de propriedade dos widgets.
## 08–11 Action Flow Editor (modal)
3 colunas: [gatilhos do widget: busca + "+" | lista com contador de erros e lixeira] [canvas do fluxo: nós com "+" acima/abaixo, ↑ ↓ reordenar, ⋮ menu] [painel "Define Action" do nó selecionado]
"+" entre nós oferece: Add Action, Add Conditional, Add Loop, Add Parallel, Add Try / Catch, Paste Action(s)
Condicional: painel "Set Condition for Action" com "Multiple conditions" (switch) e valor UNSET; o seletor é o MESMO seletor tipado do binding, agora "Type: Boolean", com fontes: Conditions ›, Conditional Value, Responsive Value, Page Parameters ›, Global Properties ›, Permissions ›, Inline Function, Custom Functions ›, Random Data ›…
Ramos TRUE / FALSE desenhados como caixa tracejada com "+" em cada ramo e "+" de junção abaixo.
Contador de erros de validação (badge "2") no gatilho e no topo do modal.
