### Observações transversais
- MARGIN não é universal: só aparece em widgets específicos (DropDown, RadioButton); o espaçamento externo genérico é feito por Padding do wrapper / Container.
- "Additional Flutter Properties": editor de código Dart livre ("... stands for the properties set in FlutterFlow. Add extra properties on the highlighted lines.") — NÃO aplicável a SDUI.
- Cores default de widgets apontam para papéis do tema (Primary, Alternate, Info, Secondary Background, Secondary Text, Error) — nunca hex.
- Estado por widget interativo: "<X> Disable Options" (condição + cores do estado) e "Hover Style".
- Excluir pelo canvas é bloqueado ("Cannot delete from canvas"); exclusão só pela árvore.
- Seleção múltipla com Shift+clique no canvas não funcionou nesta rodada (inconclusivo; doc afirma que existe).
